# 배그 지도자 — Windows 11 x64

다운로드: https://github.com/hoguengine-stack/pubg-map-ruler-releases/releases/latest/download/PUBGMapRuler.exe

`PUBGMapRuler.exe`를 실행합니다. 첫 실행은 인터넷에서 프로그램 전체 ZIP을 내려받고 준비하므로 시간이 걸립니다. Python·FFmpeg·Overwolf·RazerShot을 설치할 필요가 없습니다. 설치 위치는 `%LOCALAPPDATA%\PUBGMapRuler\versions`이며 최소 3GB의 여유 공간을 권장합니다. Windows 11 x64 일반 에디션을 대상으로 합니다.

다음 실행부터 최신 버전을 확인합니다. 새 버전은 다운로드를 마친 뒤 실행하며, 이미 설치한 버전은 다시 압축 해제하지 않습니다. 연결 또는 다운로드가 실패하면 안내 후 기존 버전을 실행합니다. 첫 실행은 인터넷이 필요합니다. 이미 프로그램이 실행 중이면 설정 창의 종료 버튼으로 닫은 뒤 다시 실행합니다.

프로그램이 `준비 완료` 상태가 되기 전에는 새 버전을 현재 버전으로 확정하지 않습니다. 이전 버전과 사용자 설정을 보존하며 게임이나 실행 중인 프로그램을 강제로 종료하지 않습니다. 프로그램 자체 업데이트는 EXE를 실행할 때 수행합니다.

1. 배그를 테두리 없는 창 모드 또는 창 모드로 실행합니다.
2. 설정 창에서 실제 팀 번호를 선택합니다: 1 노랑, 2 빨강/주황, 3 파랑, 4 초록. 저장되며 필요할 때 변경합니다.
3. 원본 지도를 열고 `Alt+M`을 눌러 오버레이를 켭니다. `M` 또는 `Esc`는 끄기, `F8`은 전체 일시정지/재개입니다.
4. `Ctrl+우클릭`: 내 위치부터 목표까지 거리와 목표 150m 원·150m 전 기준까지 남은 거리를 표시합니다. 234km/h는 사용자가 정한 낙하 기준이며 실제 속도나 낙하산 상태 감지가 아닙니다.
5. `Alt+우클릭` 두 번: 비행 경로 양옆 700m 초록 경계, 1km 주황 경계를 표시합니다.
6. `F7` 두 번: 지도의 가로/세로 1km 격자를 클릭해 거리 보정. `F9`: 측정 삭제. `Ctrl+Shift+F12`: 종료.

확대·축소·드래그 중에는 오버레이를 숨기고 정지 확인 후 갱신합니다. 핑과 플레이어가 겹치거나 위치가 불확실하면 거리를 숨깁니다. 자원 종류는 설정에서 선택합니다. 사녹 기초자원 자료와 미라마 실제 게임 검증은 아직 없습니다.

총성 예상 원은 설정에서 켭니다(기본 꺼짐). 먼저 원본 지도를 한 번 인식시킵니다. 베릴·SLR·MK12 일반/소음기 음색을 비교하고 앞쪽 가정으로 거리 예상 원과 물결을 표시합니다. 비슷한 후보는 100m 이내 범위로 표시하며 10초 뒤 사라집니다. 앞뒤 구분과 모든 총기 지원은 없습니다. 원본 녹화·검사용 WAV는 프로그램에 포함하지 않으며 작은 계산 기준만 들어 있습니다. 기존 검사에는 베릴 400m→500m 오답과 약한 소리 미검출이 남아 있습니다.

설정과 로그: `%LOCALAPPDATA%\PUBGMapRuler`. 소스·검증 자료는 비공개이며, 공개 릴리스에는 EXE·프로그램 ZIP·사용법·업데이트 정보만 있습니다. 무설치 패키지와 오프라인 검사는 확인했으나 새 PC GUI 및 실제 게임 수신/입력은 별도 확인이 필요합니다.
